# Usage patterns

- "Studio: build a Sortior Blader with GOAP, combat, story, visual art, animation, sound and integration." → one Issue, one bounded spec, independent QA for each producer, code source gates, owner review.
- "Studio: add this to my GitHub Project board." → deduplicate or create the Issue and link the real board through configured Projects V2 access.
- "Studio: continue the failed QA of FEATURE-13." → fetch the exact previous subject revision, workgroup ownership, findings and checkpoint; never restart from scratch.
- "Studio: make a Terrain3D editor tool." → verify the approved fork, donor parity and source SHA before admitting code.
